# Gloubiboulga theme park

# How play

You can move the camera using the ZQSD keys (or WASD in QWERTY) and rotate it by moving the mouse while holding the right-click button. 
To spawn visitors or a crowd, simply click on one of the buttons that contains the word "spawn". You can also increase or decrease the maximum number of visitors per point of interest 
by clicking the "+" or "-" buttons next to the name of the point of interest. Additionally, you have the option to teleport to a point of interest by clicking the small button located to the right of the ones mentioned earlier.
Regarding the POIs, there is a fifth one not displayed on the HUD, the "CatBus", which can be found to the left of the starting point. It is not possible to modify the number of visitors for this bus, by design.
You can quit the game by pressing escape.
